# FUTURE_DS_01 - Business Sales Performance Analytics

## Project Overview
This project analyzes Superstore sales data to identify revenue trends, top-selling products, category performance, and regional sales performance.

## Dataset
Superstore Sales Dataset

## Tools Used
- Microsoft Excel
- Excel Charts
- GitHub

## Key Insights
- Technology is the highest-performing category with total sales of 836,154.03.
- West region has the highest sales at 725,457.82.
- Sales increased strongly from 2015 to 2017.
- Canon imageCLASS 2200 Advanced Copier is the top-selling product.

## Recommendations
- Focus marketing and inventory on high-performing Technology products.
- Investigate the lower sales performance in the South region.
- Maintain sufficient stock for the top-selling products.
- Analyze the factors behind the strong sales growth from 2016 to 2017.
